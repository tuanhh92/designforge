# Thư viện mẫu — tủ xưởng đã làm

Mỗi mẫu là một thư mục: ảnh (khách gửi hoặc chụp tủ thành phẩm) + kích thước thật.
Dùng để đo AI nhận diện đúng tới đâu, và chọn ví dụ hay đưa vào prompt.

```
mau/
  2026-10-tu-ao-anh-minh/
    anh-1.jpg            # ảnh khách gửi / ảnh mặt trước
    anh-2.jpg            # (tuỳ chọn) góc khác
    thong-tin.yaml       # kích thước & bố trí thật — chép từ _mau-vi-du/thong-tin.yaml
    ban-ve.pdf           # (tuỳ chọn) bản vẽ xưởng đã làm
```

Bắt đầu với 10 mẫu, mục tiêu 30–50. Ưu tiên đa dạng: cánh lùa / cánh mở, 2–4 khoang, nhiều màu ván.
Ảnh khách hàng có thể chứa thông tin cá nhân (nhà, người) — chỉ lưu ảnh khách đã đồng ý.
