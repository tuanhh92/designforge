# Từ vựng xưởng ↔ tên trong hệ thống

Dùng đúng các tên này khi viết hướng dẫn, khi nhờ Cursor viết code, và khi trao đổi với AI.

| Xưởng gọi | Trong code (`role` / khoá) | Ghi chú |
|---|---|---|
| Thùng tủ | `carcass` | Hộp tủ: hông, nóc, đáy, hậu, vách |
| Hông trái / hông phải | `gable` (`gable_l`, `gable_r`) | Chạy suốt chiều cao thùng; nóc và đáy nằm **giữa** hai hông |
| Nóc / đáy | `top` / `bottom` | |
| Hậu | `back` | Lắp vào rãnh trên hông, nóc, đáy |
| Vách ngăn (vách đứng) | `divider` | Chia thùng thành các khoang |
| Khoang | `section` | Đếm từ trái sang phải, nhìn từ mặt trước |
| Ngăn (trong một khoang) | `compartment` | Xếp từ dưới lên: treo áo, đợt, (sau này) ngăn kéo |
| Đợt di động | `adjustable_shelf` | Gác lên chốt, lỗ hệ 32 |
| Đợt cố định | `fixed_shelf` | Bắt liên kết vào hông/vách, ngăn cách các ngăn |
| Cánh mở | `door` | Bản lề, theo từng khoang |
| Cánh lùa | `sliding_door` | Một bộ cánh cho cả tủ, chạy trên ray đôi |
| Ray trên / ray dưới | `sliding_track` (`rail_top`, `rail_bottom`) | Nhôm, cắt theo chiều dài lọt lòng |
| Thanh treo | `hanging_rail` | Nhôm oval, cắt theo chiều rộng khoang |
| Len chân | `plinth_front` | Tấm chắn chân lùi vào trong |
| Chỉ dán cạnh | `edge_band` | Cạnh L1, L2 (cạnh dài), W1, W2 (cạnh ngắn) |
| Kích thước hoàn thiện | `length`, `width` | Sau khi dán chỉ |
| Kích thước cắt | `cut_length`, `cut_width` | = hoàn thiện − độ dày chỉ ở các cạnh có dán |
| Vân gỗ | `grain` | `length` = vân dọc theo chiều dài tấm, không được xoay khi xếp ván |
